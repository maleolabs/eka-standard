# Token: mbr- — Member

- **Token ID:** `mbr-`
- **Artifact Type:** Member
- **Knowledge Dimension:** operating token (informational)
- **Engineering Domain:** Execution (stratum 4)
- **Owned State Domains:** Content State, Existence State
- **Identity/relationship notes:** IsKnowledge false. Member line: the typed
  target of the assigned-to relationship carried by work items (sto-, ts-, bug-,
  td-, ch-, spk-); at most one target per work item.
- **Description:** The member unit expresses human ownership of work: an mbr-
  line represents a team member, and a work item carries at most one
  assigned-to relationship resolving to an mbr- line. The mbr- line is a
  data-model unit (no authentication/authorization semantics). Exempt from R10
  stratification traceability (rule-011.md): a member line is an operating
  record, not durable knowledge.

Operating token — see tokens/overview.md for shared operating-token semantics.
