# Execution (Stratum 4)

- **Stratum:** 4
- **Token families:** rvw-, ctr-, tkt-, sto-, ts-, bug-, td-, ch-, spk-, ses-, cmt-
- **Knowledge Dimensions:** quality + operating tokens

## Purpose

Home of execution knowledge — work items, containers, tickets, reviews,
sessions, and notes that carry work through Protocol.

## Produces

Review (rvw-), Execution Container (ctr-), Ticket (tkt-), Work Items (sto-,
ts-, bug-, td-, ch-, spk-), Session (ses-), Note (cmt-).

## Consumes

Planning (plan, scope); Architecture (specification, standard, decision);
Discovery (requirement).

## Authority

Derives from Planning (transitively Architecture, Discovery); constrains
Operations.
