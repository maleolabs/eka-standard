# Rule R4: Owned-set Compliance

## Definition

The present State fields of an artifact must equal exactly the artifact type's
owned State Domains — no foreign fields, and empty-vector types carry no State
fields.

## Requirements

- The present State fields of an artifact must equal exactly the artifact
  type's owned State Domains.
- No foreign fields.
- Empty-vector types carry no State fields.
