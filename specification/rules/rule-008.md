# Rule R7: Change Log Consistency

## Definition

Every State transition must have a Change Log entry; the last entry per domain
must equal the current value; no backward transitions; no transitions without
entries; order preserved.

## Requirements

- Every State transition must have a Change Log entry.
- The last entry per domain must equal the current value.
- No backward transitions.
- No transitions without entries.
- Order preserved.

## Verdict

blocking
