# Rule R6: Classification

## Definition

The primary Knowledge Dimension must be declared and valid; a secondary
dimension is optional. The Engineering Domain is derived from the Type token;
if declared explicitly, it must be one of the five canonical domains and must
equal the Type's home domain. Classification changes never touch Identity
(P15).

## Requirements

- The primary Knowledge Dimension must be declared and valid.
- A secondary dimension is optional.
- The Engineering Domain is derived from the Type token.
- If declared explicitly, the Engineering Domain must be one of the five
  canonical domains and must equal the Type's home domain.
- Classification changes never touch Identity (P15).
